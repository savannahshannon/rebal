# REBAL source audit — October 12, 2026

Repository: [savannahshannon/rebal](https://github.com/savannahshannon/rebal). Requested branch: `kishor_dev`. Audit base: [`60e801a79e09a4911468af77d34ebf1726749a52`](https://github.com/savannahshannon/rebal/tree/60e801a79e09a4911468af77d34ebf1726749a52). Both `main` and `kishor_dev` pointed to this commit when inspected. All source links below are immutable links to that base, before the current working changes.

This is an implementation and reproducibility audit. The original multi-hour TensorFlow experiments were not rerun. The checked-in aggregate tables do not provide the raw checkpoints, split manifests, and run records needed to establish which exact code and settings produced every historical number. These findings describe the inspected source; they do not independently establish that any reported historical result is numerically wrong.

## Findings that affect interpretation

1. **The bundled baseline can include the equalization regularizer.** The framework's baseline call supplies uniform class weights but does not disable equalization ([baseline call, lines 1123–1130](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L1123-L1130)). The shared trainer adds the equalization term whenever `CFG.USE_EQUALIZATION` is true ([lines 950–964](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L950-L964)); it is enabled by default and deferred to the final 20% under the ResNet preset. By contrast, the standalone baseline runner explicitly disables it ([lines 322–326](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/baselines.py#L322-L326)). A bundled `baseline.weights.h5` from the usual main configuration therefore represents CE plus equalization, not plain CE. This matters for representation and logit-adjustment comparisons that consume that checkpoint. The `eq` and `decoupled` ablations disable the term globally, so the bundled baseline itself changes across those cells.

2. **Training and development samples are not strictly matched across the framework and standalone controls.** The framework fits per-class ECOD on the entire imbalanced training pool and only then takes its development split ([lines 1092–1114](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L1092-L1114); [ECOD fitting, lines 352–364](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L352-L364)). Thus preprocessing has already used the eventual development examples and removed selected outliers from that pool. Standalone baselines omit ECOD and implement a different split rule ([lines 344–364](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/baselines.py#L344-L364)). For five examples, the framework's `round(0.1 * 5)` allocates zero development examples, while the standalone rule allocates one. The final CIFAR test split remains separate in these paths; this finding concerns preprocessing isolation, development-set selection, and matched controls.

3. **The feature-SMOTE ablation changes more than one component.** Disabling `USE_FEATURE_SMOTE` invokes pixel-space SMOTE, feeds those balanced images into final backbone training, and skips feature cRT ([lines 1150–1205](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L1150-L1205); [cRT condition, lines 1211–1227](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L1211-L1227)). Its effect cannot isolate removing feature interpolation: synthesis space, the backbone's training distribution, and classifier retraining all change. A removal-only comparison should keep the trunk fixed and compare natural sampling, random oversampling, and SMOTE with matched classifier updates.

4. **An external generator bank needs explicit split provenance.** The supplied StyleGAN preparation script samples and cleans training images, then saves them without reserving the classifier's development split ([sampling, lines 53–69](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/scripts/prepare_cifar100_for_stylegan2.py#L53-L69); [preparation, lines 115–131](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/scripts/prepare_cifar100_for_stylegan2.py#L115-L131)). It also uses a different random-number generator and floors counts where the framework rounds them. Splitting classifier data before loading a bank does not prove the bank's generator never saw development images. The actual generator training manifest is needed to resolve this; overlap in a historical bank was not measured here.

5. **Probe defaults do not identify a no-cGAN REBAL-F run.** Both [feature probing, lines 122–147](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/feature_probe.py#L122-L147) and [post-hoc adjustment, lines 100–132](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/posthoc_la.py#L100-L132) default to the `main` checkpoint directory, while the corrected sweep uses a separate `ablate_cgan` cell for the no-cGAN arm. They reconstruct data from current global settings rather than loading saved split identities and complete run configurations. Reproducing REBAL-F requires selecting the intended checkpoint directory and proving the replay settings match it. Neither script loads the saved cRT head.

## Measurement and reporting details

- **Region labels conflicted in the base code.** Scalar metrics use index thirds, with boundaries 33/66 for CIFAR-100 and 3/6 for CIFAR-10 ([lines 1025–1029](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L1025-L1029)). The CSV writer hardcoded 33/67 ([line 1340](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L1340)): class 66 was assigned differently for CIFAR-100, and all ten CIFAR-10 classes were labeled head. Index thirds are meaningful for the repository's class-index decay schedule; they are not general many/medium/few-shot count thresholds.
- **Weighted-loss scale is a design choice to disclose, not an identified implementation error.** Effective-number weights have mean one across classes ([lines 799–805](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L799-L805)), and the loss averages weighted CE across examples before adding unchanged regularizers ([lines 952–964](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/framework.py#L952-L964)). Under imbalance, the average example weight need not be one. Consequently, reweighting also changes the classification-gradient scale relative to equalization and L2. The standalone CB implementation uses the same reduction.
- **Paired tests are exploratory unless the comparison family is specified.** The base aggregator computes paired t-tests for multiple metrics and arms and marks each unadjusted `p < 0.05` ([lines 86–127](https://github.com/savannahshannon/rebal/blob/60e801a79e09a4911468af77d34ebf1726749a52/scripts/aggregate_corrected.py#L86-L127)). Report paired seed differences and uncertainty, declare any primary endpoint, and disclose multiplicity. A nonsignificant test does not establish equivalence. For a frozen encoder, seed uncertainty also excludes uncertainty from learning the representation.

## Replication repairs verified in the current working diff

The following changes were inspected in the working diff on October 12. This confirms their implementation, not a rerun of the original learning experiments:

- `scripts/run_corrected.py` resolves the repository root correctly, checks seed/method/module identity when resuming, uses the expected results filename for each runner, isolates inherited `REBAL_*` training overrides, and exits nonzero after failures. Explicit sample-bank and per-class-FID artifact inputs remain supported through validated CLI paths or the documented environment controls and are recorded in run logs.
- Both aggregators reject incompatible dataset/protocol/seed/method records before constructing corrected comparisons. The baseline aggregator now reads corrected REBAL records by default and keeps optional legacy tables separate.
- `framework.py` now writes CSV region labels using the same class-count-dependent boundaries as scalar metrics.

These repairs improve future execution and aggregation. They do not change existing checkpoints or retroactively validate historical tables. The methodological findings above remain open unless separately addressed and rerun.

## Boundary for the new larger-data experiment

The Tiny ImageNet extension is a controlled classifier-rebalancing study on shared frozen features. It should not be described as an end-to-end replication of REBAL-F, a test of its trainable equalization term, or a cGAN experiment. An ImageNet-pretrained encoder also creates a pretraining-overlap risk because Tiny ImageNet is drawn from ILSVRC-2012. Matched train/development splits, duplicate exclusion, random-oversampling controls, held-out evaluation, exact counts, and raw per-seed records are necessary for interpreting the extension.
