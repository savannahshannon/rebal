# Vision: derived evidence in Git

This directory contains the completed aggregate, frozen protocol and selections, the 60 saved final result records, direct CSV projections, scientific audit receipts, and the prospective serialization amendment. It contains no raw logits, images, label/split arrays, features, pretrained weights or trained model/optimizer states.

`raw_evidence_catalog.json` is the exact catalog of a **separate complete local weight-free raw archive** (435 payload files). Its raw prediction members are not included in this Git directory. `derived_evidence_manifest.json` lists only the files actually present here. Raw predictions remain in the local research archive and are excluded from the Git upload.

The six model/loss arms each have ten optimizer seeds (10–19). The direct tables preserve 180 endpoint rows: 120 confirmation readouts (raw and prior-adjusted) and 60 official-evaluation exploratory readouts. They contain 36,000 per-class rows, 2,460 calibration candidates, 108 summary rows, five primary paired contrasts, and 50 paired seed differences. All CSV values are copied from completed saved JSON records; no metric, statistic, calibration choice, or model prediction is recomputed by this export. Macro-F1-selected log-prior offsets do not establish probability calibration.

The original numeric audit checked 60 final models, 180 readouts and 72 development captures. The separate actual-state audit verified 72 local checkpoint states (12 tuning and 60 final), with 15 epochs and 1,800 AdamW steps per trainable parameter. The portable numeric audit replayed stored numeric evidence with zero checkpoint loads and zero checkpoint-file hash checks. The Git directory itself contains no raw predictions or checkpoint tensors, so those audits cannot be fully rerun from the small Git set alone. Their stated limitations remain in the copied receipts.

The frozen result identifier `balanced_softmax_vs_ce_dino_frozen` is retained in these exact records and tables. The global analysis helper maps only that identifier to its pre-existing canonical report name `balanced_softmax_vs_ce_dino`; the contrast and family are unchanged (see `docs/followup_analysis_compatibility.md`). Full numeric replay requires the local archive and `scripts/verify_vision_followup.py`; actual checkpoint auditing additionally requires the preserved local states. The study compares selected pipelines on one shared split; pretrained-data independence and architecture-isolated causal effects are not established.
