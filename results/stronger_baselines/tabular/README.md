# Covertype: derived evidence in Git

This directory contains the completed four-family aggregate, protocol, frozen choices, five saved table exports, 40 saved calibration choices/curves, and original plus portable verification receipts. It contains no raw predictions, labels/split arrays, tabular input rows, feature arrays, pretrained weights, trained checkpoints, or private operational logs.

`raw_evidence_catalog.json` is the exact catalog of the **separate complete local weight-free raw archive** (286 payload files). Its raw prediction members are not uploaded here. `derived_evidence_manifest.json` inventories only the files actually present in this Git directory. Independent numeric replay requires the supplied local archive, not this small derived set alone.

The four model/objective families each use ten final optimization seeds (10–19), after two tuning trials per family at seed 9. The copied tables retain 64 summary metric rows, 80 raw/LA per-seed readouts, 560 per-class rows, 40 runtime rows, and three primary paired comparisons. Forty exact calibration JSON records retain all 320 candidate scores and each selected decision offset. These records are copied from completed saved evidence; this preparation performs no inference or scientific metric/statistical recalculation. The log-prior decision offsets were selected for macro-F1 and do not establish probability calibration.

The original actual-state audit covers 48 trained model fits/identities (8 tuning plus 40 final) across 84 weight files: 36 best and 36 last neural checkpoints, plus 12 boosted-tree artifacts. The separate original integrity/selection overlay checks 78 selected artifacts; those coverage counts describe different checks. The portable integrity replay checks zero model-weight artifacts and zero neural checkpoint states. Its numeric self-replay is supplemented by the separate final-prediction verifier, which imports no scientific runner and replays all 40 prediction cells, 80 readouts, 40 eight-candidate calibration curves, 640 scalar metrics, 1,680 per-class values and 3,920 confusion entries. It crosschecks independent NumPy formulas against scikit-learn, loads zero model weights, and performs no model inference or retraining. The three-contrast statistical replay separately verifies all 30 paired differences and the within-study Holm family.

The frozen training protocol completes 50 neural epochs (9,950 MLP or 19,900 FT updates) or 600 boosting rounds; tuning selects the reported boosting iteration among 50-round intervals through 600. See `docs/tabular_followup.md` for current commands and the public helper documentation correction. The bundle-root receipts document fresh portable replay; `production_model_provenance` retains original working-run receipts. Ten seeds quantify optimization variation on one fixed Covertype partition, rather than uncertainty across external datasets or geography. Shared-machine and resumed timings do not establish isolated efficiency.
